# Следующая итерация

Прототип не зависел от ответов на эти вопросы. Прикреплённый референс-промпт не был доступен в сообщении или каталоге; реализация основана на описании задачи.

## Что уточнить у пользователя

1. Целевые роли, уровень, ключевые навыки и отрасли — заполнить первый профиль.
2. Допустимые страны найма, право на работу, часовые пояса; достаточно ли «remote Europe» или нужен найм из Молдовы.
3. Зарплата: валюта, gross/net, месячная или годовая ставка, допустимые типы контракта.
4. Приоритет поиска: сначала список компаний или широкий поток вакансий.
5. Нужна ли Adzuna для выбранных стран; если да — личные ключи разработчика.

## Осознанные границы текущей версии

- Загрузка по кнопке, без фонового демона и расписания. Даты следующего действия показываются внутри приложения, системных уведомлений нет.
- Релевантность основана на текстовых совпадениях. Нет embeddings, семантической нормализации ролей, автопроверки права на работу или LLM-запросов.
- Нет автоматического поиска всех компаний в интернете. ATS работают с выбранными досками, расширение списка компаний идёт через ленты и импорт.
- Нет конвертации валют, уверенного разбора произвольного текста зарплаты, регионов или юридических ограничений. Неизвестные значения помечаются явно.
- Вакансии, исчезнувшие из источника, не удаляются и не помечаются закрытыми автоматически. Перед откликом проверяется первоисточник вручную.
- Дубликаты с разными ссылками разных площадок не сливаются семантически.
- API отдаёт локальную выборку целиком, интерфейс рисует карточки порциями по 40. Для десятков тысяч длинных описаний нужна серверная пагинация / SQLite FTS.
- Экспорт/импорт объединяет записи, не заменяет базу. Для побитового восстановления — копия каталога `data` при остановленном приложении.
- Обновление внешнего источника может перезаписывать поля объявления; персональные поля защищены. Для собственных выводов используйте заметки.
- Однопользовательский локальный режим. Нет авторизации, облака, синхронизации устройств, отправки откликов или сообщений третьим лицам.

## Возможные приоритеты

- Проверки страны найма и исключений с ручным подтверждением.
- Дополнительные фильтры компаний: финансирование, тип продукта, B2B/B2C, размер и география.
- История активности с контактами, действиями и ссылками на переписки.
- Расписание обновлений, проверка закрытых вакансий, уведомления.
- Специализированный источник для фактического рынка пользователя.
- LLM-обогащение только после выбора провайдера, бюджета и разрешённых к отправке данных.
